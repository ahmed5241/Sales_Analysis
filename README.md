📊 Sales Analysis | Python & Power BI
📌 Project Overview

This project presents an end-to-end retail sales analysis using Python for data cleaning and exploratory data analysis (EDA), followed by interactive dashboards built with Power BI.

🎯 Objectives
Analyze sales performance
Identify top-performing products
Understand customer behavior
